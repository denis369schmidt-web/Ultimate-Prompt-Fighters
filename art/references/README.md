# Konzeptreferenzen

Erzeugt am 2026-09-18 mit dem eingebauten Bildgenerierungswerkzeug im Modus `stylized-concept`.

## Promptzusammenfassung

- Schattenninja: orthografische Vorder-/Seiten-/Rückansicht, schlanke segmentierte dunkle Rüstung, Stoff, zwei kurze cyanfarbene Elektroklingen, neutrale A-Pose, Materialdetails, keine Logos oder Schrift.
- Lavagolem: orthografische Vorder-/Seiten-/Rückansicht, massige obsidianfarbene Platten, orange glühende Risse, übergroße Fäuste, Materialdetails, keine Logos oder Schrift.
- Arena: 16:9-Seitenansicht einer verfallenen gotischen Mondzitadelle mit freier Kampfspur, blauem Mondlicht, improvisierten Reparaturen und zwei kontrollierten Feuerakzenten.
- Größenvergleich: Ninja mit visueller Zielhöhe 1,8 m und Golem mit visueller Zielhöhe 2,35 m auf gemeinsamer Grundlinie.

Die vollständigen Produktionsentscheidungen und festgestellten Widersprüche stehen in `docs/ART_DIRECTION.md`.
